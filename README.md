Planned Rust volunteer client for Corvin distributed analysis. Intended surfaces: acquire and submit analysis jobs over the worker HTTP protocol against [server](https://github.com/corvin-chess/server), host a local [engine](https://github.com/corvin-chess/engine) binary, and return signed results for dual-assign verification. Depends on [chess-core](https://github.com/corvin-chess/chess-core) for rules context and [engine](https://github.com/corvin-chess/engine) for search. No third-party engine or weights. No volunteer client source is in this repository yet.
